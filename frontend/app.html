    Figure 8. System Architecture of the Study

    Resolving Morphological Overlap in Infectious Skin Diseases: An ITA-Guided Adaptive L*-CLAHE and Fine-Grained YOLOv26 Framework for Localization and Classification on Melanin-Rich Filipino Skin

    A. Offline Training & Calibration
    (Performed strictly before deployment; isolated environment)
    1. Public Foundation Dataset 70/20/10 Split

    Curated dermoscopic and clinical images across Fitzpatrick Skin Types I–V from public foundation datasets (DermNet, Kaggle).

    2. Phase 0: ITA Calibration Mapping Gate

    Computes Individual Typology Angle (ITA) on training data to empirically calibrate enhancement thresholds (β_high, β_mid, β_low) and define continuous mapping function:

    clip_limit = f(ITA) = clamp(4.4 - 0.045 × ITA, 2.0, 4.0)
    3. Stage 1: Localization Learning YOLOv26 Head

    Classification head frozen. Only bounding box regression losses (CIoU and DFL) and objectness loss active. Learns spatial boundaries and geometric lesion contours.

    4. Freeze Selected Backbone Layers CSP-Darknet

    YOLOv26 CSP-Darknet backbone and localization heads locked to prevent catastrophic forgetting and feature degradation.

    5. Stage 2: Fine-Grained Classification Focal Loss

    Unfreezes classification head to focus on disease-specific morphology (texture, crusting, scaling, annular borders) using Focal Loss:

    FL(p_t) = -α_t (1 - p_t)^γ log(p_t)
    ★ Clinical Hold-Out Set (Testing Set B) 5-10% Total

    Philippine local clinical hold-out set is kept entirely outside the 70/20/10 split. Never used during training/validation; used purely as real-world out-of-distribution domain stress test.

    B. Online Inference & Evaluation
    (Deployed real-time runtime; no weight updates; frozen thresholds)
    1. New RGB Lesion Input Patient / Clinician

    User uploads camera capture or clinical test image.

    2. Skin-Tone-Adaptive Preprocessing CIELAB Space

    RGB converted to CIELAB. K-means clustering (Silhouette score) extracts healthy skin mask. Computes:

    ITA = arctan((L* - 50) / b*) × (180 / π)

    Adaptive L*-CLAHE enhancement applied using frozen clip limit; recombined with chromatic a*, b* into normalized RGB tensor.

    3. Deployed YOLOv26 Model Frozen Weights

    Runs single forward-pass inference. Does not update weights or recalibrate ITA. Generates 3 parallel output streams.

    4. Parallel Model Outputs 3 Payload Streams
    • Localization: Bounding boxes, coordinates (xmin, ymin, xmax, ymax) and IoU.
    • Classification: 8-class disease label and confidence score.
    • Explainability: Grad-CAM heatmap attention for morphology validation.
    5. Dedicated Dual System Views Output A & B
    • Technical Dashboard (Output B): Clinical audit, latency, GFLOPs, bounding boxes, raw XAI tensor activations.
    • Patient View (Output A): Simplified disease label, local name, confidence score, Grad-CAM overlay, RA 10173 disclaimer.
    Controlled Ablation Study Design (Models A – D) Experimental Protocol

    Evaluating performance improvements across Fitzpatrick Skin Types I–V with analytical emphasis on melanin-rich Types III–V within the Philippine clinical domain.
